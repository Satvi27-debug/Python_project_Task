# 🐍 Python Data Processing & Preprocessing Projects

This repository contains three Python projects created to practice **Python fundamentals, NumPy, Pandas, and data preprocessing techniques**.

## 📚 Projects

### 🛒 Task 1 — Shopping Cart & Python Concepts

A simple shopping cart program demonstrating important Python concepts.

**Concepts covered:**
- Default function arguments
- Mutable vs immutable objects
- Mutable default argument pitfalls
- Lists, dictionaries, and tuples
- Functions and modular programming
- Loops and data structures
- Exception handling
- Basic billing logic

The project demonstrates why using a mutable default argument such as `cart=[]` can cause unexpected behavior and how to fix it using `None`.

---

### 🎓 Task 2 — Student Data Preprocessing

A student dataset is cleaned, processed, and analyzed using **NumPy and Pandas**.

**Operations performed:**
- Loaded and explored the dataset
- Calculated mean, median, minimum, and maximum scores
- Normalized scores using NumPy
- Checked data types and missing values
- Filtered students based on attendance
- Handled missing values
- Converted data into correct formats
- Converted exam dates to datetime
- Detected and handled outliers
- Removed duplicate records
- Created an average score column
- Found the top 5 students
- Calculated correlation between attendance and marks
- Grouped students by gender

**Technologies:**
- Python
- NumPy
- Pandas

### 👨‍💼 Task 3 — Employee Data Preprocessing

An employee dataset is cleaned and prepared for further data analysis or machine learning.

**Dataset contains:**
